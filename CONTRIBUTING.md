# Contributing

Issues and pull requests are welcome, from anyone and especially from people
who use or run the e-Visa service.

- **Content fixes** (visa terms, ports, FAQs, helpdesk numbers): edit
  `seed/content.mjs` and cite the official page the change comes from.
- **Design or accessibility changes**: include a screenshot at desktop and
  phone width, in light and dark mode.
- **Code**: no build step and no runtime dependencies. Keep it that way unless
  there is a clear reason. Run `npm start` and check the change in a browser.

Do not commit API keys, real applicant data, or screenshots that contain
either.
